# Welcome

This is the Ares ASM user guide — a placeholder page. Content goes here as it's written.

Pages in this `docs/` folder describe the **current, unreleased** version of the platform. When a
release is tagged (`vX.Y.Z-betaN`), `scripts/build-versions.sh` snapshots this folder into a new
versioned copy so past releases keep their own docs — see the repo root `ares-docs/README.md`
for how that works.
